Session date: 2026-03-16

Six ideas generated:
1. Conversation Remix — branching/forking conversations into a tree (like Git for thinking)
2. Memory Replay / Memory Digest — weekly AI-written journal entry from persistent memory
3. Prompt DNA — live, collapsible panel showing exactly what system prompt was sent
4. Anura Missions — one-click guided autonomous task templates wrapping Anura OS
5. Collaborative Rooms — real-time shared conversations via Supabase Realtime (viral acquisition loop)
6. Spark Feed — AI-initiated conversations based on memory + fresh web search results

Meta insight surfaced: Tripplet has more contextual depth than competitors but none of it is currently visible or emotional. The winning move is surfacing existing depth, not adding new features.

Hot lead: `src/app/spark/page.tsx` already exists — the Spark Feed concept was already anticipated. Recommended as the highest-leverage next build target.

**Why:** Creates daily active usage habit loop, leverages existing memory system, no new UI patterns needed.
**How to apply:** When user asks what to build next, point to Spark Feed first.
