---
name: Hard UI Rules
description: Design elements explicitly banned from the Tripplet UI — must never be added under any circumstance
type: feedback
---

Never add SuggestedPrompts, SuggestionChips, prompt grids, or recommendation chips anywhere in the app — especially not near the chat input or in the empty state.

**Why:** The user has explicitly and permanently banned these elements. They are considered clutter and a design crime on this platform.

**How to apply:** Do not suggest or implement these even as "polish," "onboarding help," or a small idea. Not now, not ever.

---

Never add depth/exchange counter pills in the chat area.

**Why:** The user despises these. They were previously removed after strong negative feedback.

**How to apply:** Do not reintroduce any pill, badge, or counter that tracks conversation depth or message exchange count in the chat UI.
