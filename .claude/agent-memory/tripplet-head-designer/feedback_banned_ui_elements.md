Never add any of these UI elements:

1. **SuggestedPrompts / SuggestionChips / prompt grids / recommendation chips** near the chat input or empty state.
2. **Depth/exchange counter pill** in the chat area — it is permanently removed.

**Why:** The user has explicitly called these out as unwanted. They were likely added before and the user hated the clutter and noise they added to the interface.

**How to apply:** Before shipping any "polish" pass or finishing task on chat/input surfaces, check that none of these have crept back in. Do not sneak them in as alternatives or variants.
