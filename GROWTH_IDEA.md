# Growth Idea: Tripplet "Proof Links" — every answer becomes a shareable, forkable landing page

> Status: PROPOSED · Owner: Alex · Generated 2026-07-07
> An acquisition idea, not an implementation. Nothing here has been built.

## 1. The problem this solves

Tripplet has a great product surface (chat, deep-research, study mode, User
Memory, web search, and the `@anura` sandboxed VM) — but its growth loop is the
same one every AI chat app has: a person signs up, uses it privately, and nobody
else ever sees the output. Every ChatGPT/Grok/Claude clone competes on the *same*
zero-virality mechanic. The best answer a user ever gets dies inside a private
thread.

The unique, different move is to make **the output itself the ad.** Not a
referral code, not "invite 3 friends" — the actual work product a user is proud
of becomes a public artifact that pulls the next user in.

## 2. The idea — "Proof Links"

When a Tripplet answer is good — a deep-research report, a study guide, an
`@anura` task result, a generated mini-app — the user hits **Share** and Tripplet
mints a **Proof Link**: a clean, public, standalone page (`trippletspark.com/p/<slug>`)
that renders that answer beautifully, credits the exact model that produced it
(Astro 5 / Taipei 4 / …), and — this is the growth mechanic — ends with a live
**"Fork this in Tripplet"** button.

Three things make a Proof Link different from a normal "share chat" feature:

1. **It's a real landing page, not a transcript.** Deep-research output renders
   as a cited article; study output as a flashcard/quiz page; an `@anura` result
   as an interactive embed. It's genuinely worth sending to a colleague.
2. **It's forkable, and forking requires an account.** Any visitor can read it,
   but the moment they click "Continue this research" / "Make my own version,"
   they land in a pre-seeded Tripplet chat — that's the signup wall at the highest
   possible intent, exactly like the limit-wall upgrade moment in the existing
   monetization plan (`PRODUCT_PLAN.md` §2). Read is free; **doing** converts.
3. **It carries provenance.** Each page says "Generated by Astro 5 on Tripplet"
   with the mode used. That's an honesty signal in an AI-slop-flooded web, and it
   markets the *models* by name — turning the model lineup into a brand.

## 3. Why this is the right loop for Tripplet specifically

- The high-value modes (`deep-research`, `study`) produce **document-shaped**
  output that is inherently shareable — unlike a one-off chat reply. The share
  artifact is a byproduct of the feature users already want.
- `@anura` results are *interactive* — a shared sandbox result is far stickier
  than a screenshot and is something no text-only competitor can mint.
- User Memory means a forked Proof Link can pre-load context, so a new user's
  first message already feels personalized — a strong first-run "wow."
- It reinforces monetization instead of fighting it: heavy Proof-Link creators
  hit the limit wall faster → the existing upgrade CTA does the rest.

## 4. The viral math (why it can actually move numbers)

Standard AI chat apps have viral coefficient ≈ 0 because output never leaves the
app. Proof Links target the two levers:
- **Shares per user (β):** every genuinely good answer is one tap from a public
  page. Aim for the "I'd text this to someone" reports.
- **Conversion per view (γ):** the fork button sits at the bottom of a page the
  visitor already found useful — intent is pre-qualified, not cold.

Even a modest β·γ per active user compounds because creation is continuous
(people research/study daily), not a one-time invite ask.

## 5. Anti-slop / trust guardrails (turn the risk into the pitch)

Public AI pages are a spam vector, so the design has to earn trust — and that
becomes the differentiator:
- **Model provenance badge** on every page (which model + mode produced it).
- **Citations preserved** for `deep-research` output (the sources are already
  fetched via the `BACKEND_URL` search service — surface them).
- **`noindex` by default; opt-in to public indexing.** Owner controls SEO
  exposure; prevents a flood of thin pages hurting the domain.
- **Rate-limited minting** reusing `src/lib/security/rate-limit.ts`.

## 6. Rough shape (where it plugs into the existing app)

| Piece | Where |
|---|---|
| "Share as Proof Link" action | message actions in `src/hooks/useChat.ts` / message UI |
| Mint endpoint (snapshot answer + model + mode → slug) | new `src/app/api/proof/route.ts` |
| Stored artifact | new `ProofLink` model in `prisma/schema.prisma` (slug, userId, model, mode, contentJSON, isPublic, views) |
| Public render | new `src/app/p/[slug]/page.tsx` — SSR, mode-specific templates |
| "Fork in Tripplet" → seeded chat + signup wall | reuse guest/auth flow; pre-load context via User Memory |
| Abuse controls | `rate-limit.ts`, `noindex` meta, provenance badge |

## 7. First test (cheap, one week)

Ship Proof Links for **`deep-research` output only** — the single most
shareable, most "look what I found" surface. Measure: share rate per report,
views per link, and fork→signup conversion. If deep-research pages convert,
extend to study and `@anura`. If they don't, we learned it for the price of one
render template and one endpoint.

## 8. Out of scope / follow-ups

- SEO strategy for opt-in public pages (could become an organic acquisition
  channel on its own — "how to X" research pages ranking).
- Creator leaderboard / profiles (a page of a user's best Proof Links = personal
  brand → recurring distribution).
- Team/enterprise: private Proof Links as internal shareable research (ties to
  the paid tiers in `PRODUCT_PLAN.md`).
